# Campus Agent — 产品愿望与范围

> 状态：active
>
> Owner：Wish
>
> 依据：2026-11 与用户关于校园通知、BYOK、免费部署、关注与申请进度的连续讨论

## 北极星目标

即使学校行政老师没有转发、学生没看到邮件，也能及时发现**公开可访问**的学校/学院通知，知道自己是否需要进一步核对资格、材料、申请窗口，并能持续跟踪到自己的行动完成。

## P0 — 必须可靠解决

1. **发现**：汇总 MIT / 浙江大学 / 清华大学等校公开通知。先确保已有的 ZJU 人工智能学院可用，再逐步接入其他来源。公开索引不依赖学校账号或 WebVPN。
2. **关注**：学生可自由关注多个学院与跨学院主题（奖学金、博士招生、课程、活动），有选择地接收，来源状态透明。
3. **理解**：普通搜索无需 AI；有 BYOK（Kimi、DeepSeek、OpenAI/兼容 URL）后可对官方通知提问，所有回答保留原文链接。
4. **Progress**：公告发布到最后期限形成“长条”申请窗口。时间经过和“已完成”分开。至少显示未开始、进行中、已完成、已逾期、还剩几天。
5. **今日看板**：用户可以明确标记状态；7天内未完成和逾期项目集中显示，完成记录保留。**绝不根据候选日期自动冒充正式截止日**。
6. **官方跳转**：点击通知进入学校官网；本站不抢占学校官方办事系统角色。

## P1 — 值得后续迭代

- 更准确、可复核的截止日/资格结构化抽取与人工审核流程，支持一份通知多个申请类别、多个阶段、多个截止日。
- 可选 Apple Calendar / Google Calendar 外部日历显示，优先 **只读单向同步**；保持站内任务状态为权威。
- 免费、可靠的异常/失败告警、避免重复通知、用户配置的关注提醒（注意真正的后台推送能力尚未上线）。
- 跨设备备份/迁移个人任务，逐步设计独立用户身份，不向公开 GitHub 数据仓同步个人记录。
- 班车时刻表、官方文件检索与学校生活服务入口。

## P2 — 远期探索，非首版

- 正式接入学校教务/公文/OA 与校内身份，依赖学校各系统权限许可。
- AI 代填 Word/PDF、自动提交奖学金、自动审批或在第三方网站执行高权限动作。
- 多个日历平台的双向完成状态同步、Notion 工作区数据库映射、原生 iOS App。
- 商业收费、付费后台、多模型集中代付、无限制动态 Agent 执行。

## 当前硬约束

- **尽可能零成本**：Vercel Hobby 承载前端及少量 BYOK API；GitHub Actions 在独立 `campus-agent-data` 仓库刷新公开信息；不用 Cloudflare、不建个人专属高成本服务器。
- **个人自带模型**：网站不能依靠聊天中的 ChatGPT 持续在后台工作；没 API Key 仍应可用。
- **学生隐私**：不上传校园密码或受限资料；个人选择与任务完成状态先留在自己浏览器，不对其他用户公开。
- **校园权威**：来源链接、原始日期、申请条件都应能核对。截止日候选和个人核实状态必须不同。
- **页面简洁**：偏向 Linear Inbox + 阅读式列表；信息按是否需要行动组织，避免占据首页的大量统计卡、装饰和空面板。

## 第一版验收场景

给一名 ZJU AI 学院学生：默认关注人工智能学院；他可再关注计算机、软件学院，并额外订阅奖学金；从一条招生公告点开官网，手动核实其中自己需要的截止日，加入 Progress；两天后回到网页看到还剩几天；自己标记完成后刷新仍是已完成；可把截止日一次性导出到 iOS/Google 日历。未核实公告不能在“今天截止”里误报。

目前 P0 的**浏览器个人任务**能力为本地 MVP；**主动后台推送、用户个人服务器数据同步、日历自动订阅**仍未实现，不应把愿望当成交付。

## P1 · 交互品质的长期愿望（2026-11-20）

希望 Campus Agent 的通知列表、关注开关、Progress 时间条、今日看板与完成按钮，不只“能点击”，还要让人自然看懂**可操作、已选择、待核实、已完成**等不同含义。图标尺寸、相对位置、文字行距和留白服务于申请决策；鼠标悬停、键盘聚焦与手机触控都应给出一致且无障碍的反馈。动效不得把“时间过去了”误读成“任务完成了”，也不能把截止日候选显示得像官方确认。

**2026-11-20 的当前参考：** [nuro.dev](https://nuro.dev/) 的悬停、图标比例和空间组织。只是观察的优秀案例，不是唯一参考、照搬方案、动画参数/框架命令；以后更好的通知阅读与任务看板设计可以替代它。

后续实现应先沿用 `docs/design/` 和实际前端 owner，做真实桌面与 440px 手机对比，测试 focus-visible、触控、减少动态效果、无溢出/布局抖动和任务语义不变。仍优先完成 P0 官方来源核对与确认式任务逻辑，维持 BYOK 与隐私规则。**此 PR 只记录 P1 意愿，不意味着已上线功能。**
