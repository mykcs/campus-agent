# Wish — 用户愿望的唯一主表

[PRODUCT-WISHES.md](PRODUCT-WISHES.md) 记录用户想达成的结果、非目标、阶段取舍和验收标准。它不代替当前源码、测试和实际部署记录。工程人员不应将自己的建议冒充成用户已经批准的功能。

优先级规则：**P0** = 丢失奖学金/申博机会的核心痛点；**P1** = 提升可用性/覆盖面；**P2** = 需要学校授权、云端用户账户或持续付费，暂缓。

用户的新反馈先在这里更新目标，再在 Design/Dev 中处理方案。如果方案与愿望冲突，以明确的最新用户要求为准。

Feature goals and current/better design: [Feature Design](../design/features/README.md). This is part of Design, not a separate governance owner.
