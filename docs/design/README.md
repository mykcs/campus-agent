# Design — 交互体验与审美决策

Design 只描述用户可感知的体验目标，不复制完整技术实现。第一手设计规则在 [PROGRESS-UX.md](PROGRESS-UX.md)，参考案例与取舍在 [REFERENCES.md](REFERENCES.md)，视觉系统在 [STYLE.md](STYLE.md)。

设计原则：**先让学生看见必须处理的事，再允许深读通知，再进入 AI 解释**。首页是通知收件箱，不是系统健康大屏；Progress 是从公告到截止的任务时间轴，不是常规月历。外部日历适合提醒确定事件，完成状态应由 Campus Agent 掌握。

已有的浅色、紧凑 Linear/Anthropic 风格为默认基线，避免过多装饰图、统计卡、过深底色和始终空白的侧栏。桌面/手机使用同一任务模型，但信息密度按屏幕宽度递减。

验收须看**真实截图和交互**，不以设计文档文字替代可用性测试。

Feature goals and current/better design: [Feature Design](features/README.md). This is part of Design, not a separate governance owner.
