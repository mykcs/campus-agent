# Campus notices to personal actions

稳定 ID：`notice-to-action`；范围：Notice inbox / Progress / today board。

## 目标与来源

即使没有收到转发，也能从官方公开通知发现机会，选择关注学院和主题，核实资格与截止日期，再跟进到个人行动完成。首页先处理事项，再读详情，再选择使用 AI。

依据：[现有 Wish](../wish/PRODUCT-WISHES.md)、[现有 Design](../design/README.md)，2026-11-26 按已有仓库内容整理；不引用私人聊天，不宣称获得新的用户批准。

## 保护的体验与语义

公开来源与官网跳转可核对；截止日候选不等于用户确认截止日。Progress 的时间经过与完成状态分开，已完成历史保留；七天内与逾期未完成事项集中显示。无模型 key 仍能搜索；个人状态不写入公共数据仓。一次性日历导出不冒充连续同步；不宣称尚未验证的后台提醒。

允许更优布局、交互和技术实现；保留上述来源明确的目标。新目标或被否定方案应记录来源及时间；不得将暂时做不到的能力从意图中删除。
